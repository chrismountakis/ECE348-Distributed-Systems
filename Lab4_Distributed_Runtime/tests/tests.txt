Stage 4 - Shutdown
  
  Shutdown when alone
  # Terminal A  only (python runtime.py)
  >> run tests/lb_test.ss
  >> shutdown
  Expected: prints No peers available. Shutdown cancel. Thread still visible with list.

  Shutdown with a peer - thread and tuple space migrate
  # Terminal A  (python runtime.py)
  >> run tests/lb_test.ss
  >> shutdown
  
  # Terminal B  (python runtime.py 10001)
  Expected: A prints Shutdown complete. B prints Arrived from ... and shows the thread in its list.


Shutdown correctly refused after peer leaves
  # Terminal A                              Terminal B
  >> run tests/lb_test.ss                   
                                            >> exit
  # wait for A to print "Peer left"         
  >> shutdown
  Expected: A prints No peers available. Shutdown cancel - it does NOT silently shut down and abandon the thread. Without the fix, A would see the stale peer,
  attempt migration to the dead B, fail, and exit anyway.
